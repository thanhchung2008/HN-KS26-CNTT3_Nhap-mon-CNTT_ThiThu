# Dự án phát triển Web 
Đây là dự án có **tiềm năng phát triển** và có*doanh thu* lớn.

|thư mục|nội dung|
|:---:|:---:|
|logs|chứa các dòng ERROR và lịch sử thanh toán|
|docs|danh sách hàng cần nhập thêm|
|media|logo văn phòng|

lệnh powershell liệt kê nội dung dự án 
```
Get-Childitem 
```
